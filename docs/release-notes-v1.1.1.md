## opencode 启动器 v1.1.1

### 新增

- **轻量版自动更新**：启动时后台查询 GitHub 最新版本（24 小时内不重复联网），有新版在「设置 → 关于」提示；也可随时手动检查。下载后校验文件大小与格式，弹出安装向导即可完成升级。下载走 GitHub API 资产端点，在 github.com 主站不可直连的网络下依然可用。桌面版不带此功能，仍需手动下载。
- **开机自动定位最近项目**：按哪个项目的会话最近有更新判定，其次按项目添加时间；不再跟随最后一次点击的项目。

### 修复

- **没有 npm 的官方独立版安装也能查询最新版本**：维护页不再只依赖 `npm view`；npm 不存在或查询失败时，会直接请求官方 registry（失败后回退 npmmirror），因此通过官方安装脚本安装、没有 Node.js/npm 的用户也能看到最新版本。
- Electron 与 Tauri 两个版本同步处理，界面不再显示“未检测到 npm”，查询失败时统一显示“查询失败”。

### 文档

- 重写 README：按使用场景组织，去掉装饰性内容，明确轻量版为主力维护版本。

### 说明

- 自本版本起，功能开发以轻量版（Tauri）为主，桌面版（Electron）不再积极更新。
