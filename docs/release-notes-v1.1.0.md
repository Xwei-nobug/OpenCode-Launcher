## opencode 启动器 v1.1.0

**内置 Web 版，项目一处管理、处处同步。**

### 本次提供两个版本

| 资产 | 说明 | 大小 |
|---|---|---|
| `opencode-launcher-light-setup.exe` | **轻量版安装器（推荐）** — Tauri 2 + 系统 WebView2 | ~1.8 MB |
| `opencode-launcher-setup-1.1.0.exe` | 桌面版安装器（Electron 38，自带 Chromium） | ~86 MB |

两个版本功能一致，轻量版体积小一个数量级。本版起**只提供安装包**，不再发布免安装单文件。

### 新功能：内置 OpenCode Web

点顶部「**启动 OpenCode Web**」，网页版直接在启动器窗口里打开——不用开浏览器，不用手动登录。**两个版本均支持**。

- **窗口内嵌**：Electron 用自带内核，轻量版用系统 WebView2；关闭即释放，不打开时零占用
- **单例复用**：重复点击不开第二个窗口，只切到前台并补一次同步
- **自动登录**：服务有密码保护，启动器自动换取一次性配对 cookie 再载入，打开就是已登录界面
- **项目列表自动对齐**：打开时把启动器项目库写入 Web 的「工作区」面板

> 为什么需要内置：opencode 的「设置 → 项目」读服务端数据库，而主界面「工作区」读浏览器 localStorage——两者互不相通，localStorage 也没有服务端副本。用浏览器打开时工作区常常是空的。内置窗口在页面内直接写入这份列表，等价于手动「添加项目」，只是全自动。

### 项目管理：一处修改，处处同步

启动器项目库是唯一真相源：

- 启动器里加 / 删 / 改名 → Web 与终端跟着变
- Web 或终端里改的 → 启动器启动时、点「刷新」时收回来
- 删除是真删：同时清掉 opencode 里的项目记录及其会话（磁盘文件不动，有二次确认）
- 过滤幻影记录：opencode 启动服务时会把自身工作目录登记成项目，这类用户主目录 / 临时目录 / 盘根记录不再出现在列表里

### 界面调整

- 顶部精简为「刷新」「启动 OpenCode Web」「关闭 opencode」，终端统一从项目行进入
- 左侧大卡片由「当前项目」改为「**最近项目**」
- 移除「同步到 Web 版」与「书签」按钮——内置窗口已覆盖两者
- 「关闭 opencode」现在会连**内置 Web 窗口**一起关掉

### 安装

1. 下载 `opencode-launcher-light-setup.exe`（轻量版）或 `opencode-launcher-setup-1.1.0.exe`（桌面版）
2. 双击运行，选择安装位置（支持自定义），下一步完成
3. 打开后添加一个项目目录，点「启动 OpenCode Web」

> 安装包自带运行环境，无需预先安装 Node.js。首次使用若提示未安装 opencode，点「安装 / 修复」即可。

### 从源码构建

- 桌面版：`cd desktop && npm install && npm run dist`
- 轻量版：需要 Rust stable + MSVC 构建工具，`cd tauri && npm install && npm run dist`
