## opencode 启动器 v1.1.2

### 修复

- **Web 窗口现在可以把文件拖进对话框了**：此前宿主层的拖放处理器会拦截外部拖入的文件，网页里的 HTML5 拖放事件根本收不到；现已放行，直接从资源管理器拖文件到聊天输入框即可附加。
- **修复拖拽缩放窗口后输入法候选框跑到屏幕左上角**：这是 WebView2 的上游问题（真实拖拽窗口边框缩放后，输入法丢失光标位置，候选框浮到屏幕原点且不会自愈）。现在窗口尺寸稳定后会自动把焦点重锚一次，候选框回到光标下方。主窗口与 Web 窗口均生效，输入法合成中不会被打断。

仅轻量版（Tauri）更新；桌面版（Electron）维持 v1.1.1。
